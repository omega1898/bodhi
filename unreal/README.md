# Unreal project (not created yet)

Create it on the Mac during milestone M0:

1. Open the Epic Games Launcher and start Unreal Engine 5.
2. Create a new project: **Games**, then **Third Person**. Choose **Blueprint**, Target Platform **Mobile**, Quality Preset **Scalable**, and no starter content.
3. Save it in this folder (`unreal/`) and name it `BodhiGame`.
4. Before the first commit, run `git lfs install` once on the Mac, so the large `.uasset` and `.umap` files go to Git LFS instead of normal git history.

Cloud sessions never edit this folder.
